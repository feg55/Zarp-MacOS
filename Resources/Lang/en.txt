# Zarp for macOS UI strings: English, the reference file. Every other language defines exactly the same
# keys with the same {n} placeholders — the tests in Packages/ZarpCore enforce it, and also that the code
# uses every key defined here (a key the code never asks for is deleted, not left behind).
# Format: key = value. \n is a line break, {0}, {1}... are placeholders filled in by the app.
# To add a language, copy this file to <code>.txt, translate the values and add the code to
# Localization.languages (see CONTRIBUTING.md). A key missing from a language falls back to this file,
# so a partial translation still works.
#
# The first translations descend from Zarp for Windows (MIT, github.com/feg55/Zarp, src/Zarp/Lang/*.txt).
